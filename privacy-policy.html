Kebijakan Privasi

Aplikasi: Absensi QR

Terakhir diperbarui: 25 September 2026

1. Data yang Dikumpulkan

Aplikasi ini mengumpulkan data siswa yang diperlukan untuk proses absensi, yaitu: nama, NISN, jenis kelamin, dan kelas. Data pribadi seperti NIK, agama, tanggal lahir, alamat, dan nama orang tua tidak disimpan dalam sistem.

2. Sumber Data

Data siswa diperoleh melalui sinkronisasi dari aplikasi Dapodik yang dikelola oleh sekolah.

3. Tujuan Penggunaan

Data digunakan hanya untuk keperluan absensi siswa, pembuatan kartu identitas QR, dan notifikasi kehadiran kepada orang tua.

4. Penyimpanan Data

Data disimpan di server cloud (Neon/PostgreSQL) dengan akses terbatas hanya untuk pengguna yang terotorisasi (Admin, Guru, Kepala Sekolah).

5. Keamanan

Sistem menggunakan enkripsi HTTPS, JWT authentication, dan bcrypt untuk melindungi data. QR code hanya berisi ID unik (UUID), bukan data pribadi siswa.

6. Hak Pengguna

Pengguna dapat meminta penghapusan data dengan menghubungi admin sekolah.
